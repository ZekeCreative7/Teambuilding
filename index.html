Step 5 · Session Details

세션 블록을 진행안으로 구체화

각 세션 블록의 목적, 완료 조건, 진행자 판단, 리스크를 채웁니다. 이 단계가 끝나면 최종 스크립트를 조립할 수 있습니다.

Activity Recommender

현재 선택한 세션 블록을 기준으로 GPT와 액티비티를 비교하고, 선택한 안을 실제 계획에 바로 반영합니다.

1
조건 입력 & 프롬프트 생성

추가 조건을 입력하고 프롬프트를 생성하면 클립보드에 자동 복사됩니다.

2
GPT 답변 붙여넣기 & 카드로 보기

GPT가 준 JSON 결과를 붙여넣고 적용하면 추천 카드가 생성됩니다.

프롬프트를 생성하고 GPT 답변을 적용하면 추천 카드가 여기에 표시됩니다.

Activity Library

조건별 검증된 액티비티 모음입니다. 안전감·냉소·트랙 기준으로 필터링하고 현재 세션에 바로 적용할 수 있습니다.

GPT Slot Draft Import

현재 선택된 회차의 슬롯 초안을 GPT에게 받은 뒤, 아래에 JSON을 붙여넣으면 각 슬롯 입력창에 자동으로 채워집니다. 자동 반영 후에는 직접 하나씩 수정하면 됩니다.

권장 방식: 위의 슬롯 질문 프롬프트를 복사해 GPT에 넣고, GPT가 준 JSON 결과를 그대로 붙여넣으세요.
