연결 방식

선택한 조직의 긍정/부정, 약점 문항, 리스크, 저장된 GPT 분석을 세션 생성기의 Project Brief와 Feedback 맥락에 자동 반영합니다. 기존 세션 생성기의 화면과 기능은 그대로 유지됩니다.
  • Project Brief: 목적, 조직 맥락, 실패 리스크 자동 입력
  • Feedback: Pulse 근거 수치와 GPT 분석 반영
  • Decision Log: Pulse Survey 맥락 적용 기록 추가

데이터 / Firebase 관리

현재 Pulse 데이터를 구조화해 저장하고, 내년 데이터는 CSV 템플릿으로 업로드할 수 있습니다.

CSV 템플릿 / 업로드

템플릿은 현재 데이터 구조를 그대로 내려받습니다. 값을 수정한 뒤 업로드하면 대시보드가 새 데이터로 바뀝니다.

필드: recordType, year, division, category, questionNo, questionShort, questionText, fav, low, fav25, benchMed, benchChubb

Firebase 구조

users/{uid}/pulseDatasets/{datasetId} - meta: 데이터셋 이름, 연도, 생성/수정일 - company: 전사 문항/카테고리 집계 - divisions: 본부별 문항/카테고리/등급 - analysis: GPT 분석 결과 - speech: 커뮤니케이션 솔루션 결과
